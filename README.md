## 🎯 Objetivo do Sistema
Este programa foi desenvolvido em **Python** para atender à campanha de conscientização ambiental de uma companhia de saneamento. O sistema automatiza a triagem e o perfil de consumo de água dos imóveis (**comercial**, **casa** ou **apartamento**), emitindo alertas educativos e orientações personalizadas aos moradores com base no volume mensal gasto em metros cúbicos ($m^3$).

* **Linguagem:** Python

## ⚙️ Instruções para Executar o Programa

1. Certifique-se de ter o **Python** instalado em sua máquina.
2. Clone este repositório ou baixe o arquivo `app.py`.
3. Abra o terminal (prompt de comando) na pasta onde o arquivo `app.py` está salvo.
4. Execute o comando abaixo:

```bash
python app.py
